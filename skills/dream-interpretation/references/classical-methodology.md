# 中国传统占梦核心心法

> 本文件汇总《周礼·春官宗伯·占梦》《潜夫论·梦列》《列子·周穆王》《梦林玄解·占繇》及《梦占逸旨》通义，供正式解梦前先定纲领。**铁律：先辨梦源，再审梦变与时令，最后参核典籍辞条；绝不离题硬套单个名词。**

---

## 一、辨源先于查辞（三大分类体系）

### 1. 《周礼·春官宗伯·占梦》三梦与六梦

- **三梦**（占断之法）：
  - **致梦**：神灵感应或心神自致之梦。
  - **觭梦**：奇异惊怪、反常错杂之梦。
  - **咸陟**：阴阳之气咸相通陟、天地感应之梦。
- **六梦**（成因六候，《列子·周穆王》亦作“梦有六候”）：
  1. **正梦**：无所感触、心神恬淡而自梦——**最重占验**。
  2. **噩梦**（蘁梦）：惊愕、受惊吓或突变而梦——须辨外邪惊扰与吉凶警兆。
  3. **思梦**：白昼念虑牵挂、思慕忧思所发（日有所思，夜有所梦）——**多主心绪延续，占兆权重降低**。
  4. **寤梦**：睡醒交界或似睡非睡间觉察之梦——常为心神未定或近事触发。
  5. **喜梦**：心生欢悦、气机舒畅而梦——先看喜后有无反转。
  6. **惧梦**：心怀畏忌、气机郁怯而梦——须与“阴气盛”或“肾/肺虚”之病梦相区分。

### 2. 《潜夫论·梦列》十梦辨法

东汉王符《梦列第二十八》将梦细分为十类，是实占辨源的总钥匙：

| 梦类 | 核心特征 | 断法要点 |
|---|---|---|
| **直梦** | 梦中所见即现实将临之事，所见人即其人、所见事即其事 | 无须迂回比附，直接按事件吉凶与时空提示参断 |
| **象梦** | 借物象比拟象征而示兆（如以龙蛇象君子/阴人、以松柏象长寿高官） | 须按传统意象取义，忌望文生义 |
| **精梦** | 专精诚笃、夙夜祈望而感通之梦 | 视梦者诚意与所谋之事是否正大而定应验 |
| **想梦** | 白昼挂怀、嗜欲忧思所生 | “想”多于“兆”，如渴梦饮、饥梦食，勿强作吉凶外兆 |
| **人梦** | 同一梦象，因贵贱、老幼、男女、行役、居室者不同而应事各异 | 必须结合梦者现实处境转译，不可千篇一律 |
| **感梦** | 感四时气候、阴阳寒暖变化而作（如阴雨梦水、盛暑梦火） | 应归因天地节令外感，减低人事凶吉权重 |
| **时梦** | 应春秋分至、五行旺相休囚死之令而发 | 得时气生旺者吉力增，违时衰败者应减或转凶 |
| **反梦** | 极盛转衰、极衰转盛，“或吉而反凶，或凶而反吉” | 尤须察梦中“喜极而悲、危后转安、死而后生”等反象 |
| **病梦** | 脏腑阴阳偏盛偏虚、客邪所入（详参 `wuzang-bingmeng.md`） | 优先按中医藏象提示调养，不作玄学凶兆恐吓 |
| **性梦** | 素日秉性刚柔偏嗜所发（刚猛者多梦搏击，恬淡者多梦游赏） | 属平时习性投射，非突降灾祥 |

## 二、《梦林玄解·占繇》实战断法精要

### 1. 梦有不占，占有不验 / 怪异无占，寻常有验
- **初夜混梦、饱食醉酒、白昼劳思极甚之梦**：多属思梦、病梦或浊气扰神，**不必强占**。
- **鸡鸣平旦（寅卯之时）神清气爽之梦**：天地清气初升、人神最清，**古法以平旦之梦应验权重最高**。
- **离奇荒诞、无头无尾的怪异幻境**：《梦林玄解》明确指出“怪异无占，寻常有验”——越是贴近日常人伦、器物、山水行止的清醒叙事，越有占断价值；支离破碎只剩片段时，应主动降低断语确定性。

### 2. 梦变原则（起 → 变 → 终，忌死盯单象）
《梦林玄解·占繇》特立“梦变”一条：一梦之中往往屡有迁化，必须看完整事件链：
1. **由清转浊 / 由明转暗 / 由完好转破损**：传统作“好中藏变、先顺后阻”断，提示盛时防微、稳守成果。
2. **由浊转清 / 由危转安 / 破而后修 / 死而复生**：传统作“困中有解、否极泰来”断，表面似凶实则主脱厄、除旧布新。
3. **可怕惊悚但醒前消散**：主虚惊自解，重在省身定神，不可只凭开头吓人字眼断大凶。
4. **首尾反常（如梦哭而吉、梦大笑反忧）**：古占讲究“以悲为吉、以喜为防”者甚多，**必查典籍对具体动作的原文**，不可望字生义。

### 3. 梦寄原则（主客之分：应己 vs 应人）
- 梦境发生在**自己身上**（身受、己持、己行），多应自身及直系家宅；
- 梦境发生在**他人身上**（父母、配偶、子女、同僚、陌生人），须辨“梦寄”：或是对方近况感应，或是对方作为自己某类关系的象喻（如君/官象事业靠山，盗贼象暗耗破财）。

### 4. 随人判读（古称“贵贱有别”，今作“随人应事”）
古籍常按“贵人 / 士子 / 商人 / 农夫 / 孕妇 / 病者 / 狱讼 / 行人”分断同一梦象。现代解梦**严禁机械搬用古代身份尊卑**，而应一一对应转化：
- **贵人 / 官宦** → 公职管理者、带队负责人、决策者或问仕途晋升者（看权柄、名位、公文调度）；
- **士子 / 学者** → 备考、升学、求职面试、科研写作或考评晋级之人（看文昌、名声、阻滞）；
- **商人 / 市井** → 经商、创业、项目合作、投资求财之人（看财货聚散、信誉、往来）；
- **孕妇 / 闺阃** → 孕育、家庭新成员、内宅关系或家务主事之人（看安胎、家和、子息）；
- **病者 / 讼者 / 行人** → 分别对应问健康康复、纠纷官非维权、出行远游或跨城变动之人。

### 5. 谐音取象与象征转义（象梦核心技法）
古人解梦善用谐音与象数比类（需明示出处或注明“古法取象类比”）：
- 常见吉象反解与谐音：**见棺发财（棺→官）**、**身死得寿/重生**、**粪污沾身反主得财（脏污聚财）**、**大哭主喜庆散忧**、**流血主财帛或破阻（视部位与止泄定）**。
- 常见警示谐音：**食梨主分（梨→离）**、**失履或送伞防离散（伞→散）**、**见桃防逃（桃→逃）**、**见钟防终结（钟→终）**。

## 三、多典互证与证据裁决规则

正式查证时，运行 `scripts/dream_query.py` 后按下列层级裁决，**不得凭记忆编造任何一条“古籍原文”**：

1. **第一顺位：《梦林玄解》**（侧重细象、分人、分时令、梦变与占繇心法）
2. **第二顺位：《断梦秘书》**（侧重（一）（二）（三）多义分注，能精分吉凶条件）
3. **第三顺位：古本《周公解梦》二十七类**（流传最广的九百五十一句古传断辞基线）
4. **第四顺位：《古今图书集成·梦部》及先秦道藏典籍**（用《左传》《史记》《梦书》古案及《灵枢》《潜夫论》义理做定性支撑）

**冲突处理原则**：
- 若诸书结论一致（如均主吉或均分人断）：合参归纳，引据并举；
- 若诸书结论相左（如《周公解梦》言吉而《断梦秘书》分（一）吉（二）凶）：**如实并陈两说差异**，再结合梦境前后转折、时令旺衰与梦者现实处境给出倾向性合参，不删改任何一条典籍原意。
- **现代新事物**（如手机、飞机、股票、高铁、电脑）：典籍无直接条目，必须在报告中单列“古法取象类比”（如飞机类比乘风飞翔/上天、手机类比书信远音、汽车高铁类比舟车行路），绝不可把现代名词冒充古书原文。
