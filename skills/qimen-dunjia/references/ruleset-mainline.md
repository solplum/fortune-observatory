# `mainline-cn-v1` 默认规则

这个 skill 的正式排盘只使用这一套默认规则，不在正式计算里混用别的说法。

## 适用范围

- 面向中国大陆常见时家转盘奇门使用习惯
- 默认时区：`Asia/Shanghai`
- 海外用户必须先补城市或时区

## 固定规则

### 1. 时间规则

- 用户说"现在"，就按当前绝对时间起局。
- 没给时区且语境是中国大陆，默认北京时间。
- 海外用户没给时区时，先追问，不要直接排盘。

### 2. 节令规则

- 以节令切换阴遁 / 阳遁。
- 冬至到芒种：阳遁
- 夏至到大雪：阴遁
- 节气边界前后 24 小时内，输出中要明确写出"边界提醒"。

### 3. 三元规则

- 按日干支在六十甲子序列中的位置分组。
- 每 5 日为一元。
- 顺序固定循环为：上元 -> 中元 -> 下元。

这是当前版本采用的工程化固定规则，用来确保同一输入得到同一结果。

### 4. 定局规则

- 阴遁 / 阳遁与三元确定后，从固定定局表直接取局数。
- 不在正式排盘时临时切换拆补法或其他变体。

### 5. 中宫规则

- 中宫相关判断一律寄坤处理。
- 如果旬首所遁之仪或时干落在中宫，正式输出里要提示"本盘按寄坤处理"。

### 6. 天盘起点规则

- 天盘奇仪的起排参照为旬首所遁之仪（代表甲的位置）。
- 正常情况：该仪在八宫环中，直接以它为天盘起点。
- 特殊情况：该仪在地盘落入中宫（5宫）时，寄到坤宫（2宫），天盘从坤宫地盘干起排。中宫不在八宫转盘环中，寄坤后仪的"环上投影"即为坤宫地盘干。

### 7. 值符值使规则

- 值符星：旬首所遁之仪在地盘所落宫位上的那颗九星，随天盘转至时干所到之宫。
- 值使门：旬首所遁之仪在地盘所落宫位上的那道八门，本规则集中与值符同落时干所到之宫（不另做独立转门计算）。
- 如果旬首落中宫，则取寄坤后坤宫对应的星和门（天禽寄坤并入天芮，中宫无门时取死门）。

### 8. 展示规则

- 不展示完整推理链。
- 只展示关键计算结果和必要依据。
- 用户主要看到的是：阴阳遁、局数、旬首、旬空、值符、值使、关键用神。

## 不支持的情况

以下情况不进入正式排盘：

- 用户明确要求切换到别的规则，但不接受当前默认规则
- 缺少时间或地点信息
- 想让模型跳过脚本直接手算

## 历法修正与实现边界（重建版）

- 选择全部二十四节气，包括十二中气，不再只查十二节。冬至、夏至的交接瞬间切换阴阳遁。
- lunar-python 节气时刻按固定 UTC+08:00 解释，再转到输入时区。输出时刻含 UTC 偏移；年柱、月柱按同一瞬间的北京时间判断，日柱、时柱仍按当地钟表及晚子时换日。
- 门迫为门克宫。反吟字段专指星落本宫对宫，不以五行“互克”判断，也不等同整盘门反吟。
- 阴遁宫序逆排时，八神仍用值符、螣蛇、太阴、六合、白虎、玄武、九地、九天的顺序，避免双重反转。
- 年/月干为甲，按该干支六甲对应的戊己庚辛壬癸藏仪入盘，不一律代戊。
- 拒绝不存在的日期、农历闰月、夏令时跳时和重复钟表时刻。重复时刻请转成 UTC 输入。
- 三元仍是工程化五日循环，并非传统拆补或置闰法。值使仍与值符同落时干宫，未实现独立逐时推移；不可宣称已经完整实现传统时家奇门。
- 这是依据已知审计问题重新实现的修复，不声称与丢失文件逐字相同。
